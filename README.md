# Deskwork

Student study planner with tasks, Pomodoro, flashcards, and study-buddy messaging.

## Live app
**https://workspace764.pages.dev**

## Features
- Dashboard & tasks
- Focus timer (Pomodoro)
- Flashcards & streaks
- Message friends with a unique study code
- Premium early access

## How to try
1. Open the live link
2. Sign in
3. Share your study code under Messages

Built for students. Feedback welcome.
